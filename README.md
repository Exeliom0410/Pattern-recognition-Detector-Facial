# Pattern-recognition-Detector-Facial

##Link de archivos: [Detector Facial](https://drive.google.com/drive/folders/1BKf8NDDcxArf7QQ0NmfWocZEd2yHDOhH?usp=sharing)

##Instrucciones
1) Descargar openCV y python
2) No modificar la carpeta "Modelos"
3) En rostros deben ir las fotos de la persona a la cual se le quiere detectar, se recomienda fotos de frente con algunas variaciones de hacia donde se observa y muecas o espreciones
4) En el código, solo se requiere modificar la variante "CAMARA" que representa cual cámara se esta utilizando, 0 es la cámara nativa en caso de tener una y de el 1 hacia arriba son las cámaras o capturadoras, probar diferentes números de ser necesario
5) El codigo reconoce imagenes png, jpg y jpeg.
6) En caso de dar error con las imágenes, intente recortarlas para que solo se vean los rostros
